## Detailed Migration Strategy

### 1. Style Mapping (Tailwind CSS v4 & Fonts)
In Next.js, fonts are loaded via `next/font/google` and set as CSS variables:
```typescript
const inter = Inter({ variable: "--font-inter", subsets: ["latin"] });
```
In Astro, we will use `@fontsource/inter` and `@fontsource/syne`.
In [Layout.astro](file:///c:/Users/Aryan%20Sharma/Desktop/portfolio/src/layouts/Layout.astro):
```astro
---
import '@fontsource/inter';
import '@fontsource/syne';
import '../styles/globals.css';
---
```
In [globals.css](file:///c:/Users/Aryan%20Sharma/Desktop/portfolio/src/styles/globals.css), we update our font theme configurations directly:
```css
@theme {
  --color-background: #0a0a0a;
  --color-foreground: #fafafa;
  --color-accent: #ccff00;
  
  --font-sans: "Inter", sans-serif;
  --font-display: "Syne", sans-serif;
}
```
This maps the fonts directly to the classes without needing to carry over wrapper classes (`${inter.variable} ${syne.variable}`) on the `<html>` and `<body>` tags.

### 2. Smooth Scrolling (1-1 Lenis Realization)
To avoid wrapping the entire application inside hydrated React islands, we migrate the Lenis configuration from React to native JavaScript in the layout.
Original Next.js Lenis config:
```tsx
<ReactLenis root options={{ lerp: 0.1, duration: 1.5, smoothWheel: true }}>
  {children}
</ReactLenis>
```
Astro 1-1 Layout Script realization (inside [Layout.astro](file:///c:/Users/Aryan%20Sharma/Desktop/portfolio/src/layouts/Layout.astro)):
```html
<script>
  import Lenis from "lenis";

  // Match original options 1-1
  const lenis = new Lenis({
    lerp: 0.1,
    duration: 1.5,
    smoothWheel: true,
  });

  function raf(time: number) {
    lenis.raf(time);
    requestAnimationFrame(raf);
  }

  requestAnimationFrame(raf);
</script>
```

### 3. Static MeshBackground Component conversion
[MeshBackground.tsx](file:///c:/Users/Aryan%20Sharma/Desktop/portfolio/src/components/ui/MeshBackground.tsx) does not contain interactive state or hooks. We rewrite it into a native `.astro` component to compile directly to static HTML with zero client-side JavaScript.
[MeshBackground.astro](file:///c:/Users/Aryan%20Sharma/Desktop/portfolio/src/components/ui/MeshBackground.astro) format:
```astro
---
---
<div class="absolute inset-0 z-0 pointer-events-none overflow-hidden">
  <div 
    class="absolute inset-0 opacity-[0.6]"
    style="
      background-image: 
        linear-gradient(to right, rgba(255, 255, 255, 0.1) 1px, transparent 1px),
        linear-gradient(to bottom, rgba(255, 255, 255, 0.1) 1px, transparent 1px);
      background-size: 50px 50px;
      mask-image: radial-gradient(circle at center, black, transparent 80%);
      -webkit-mask-image: radial-gradient(circle at center, black, transparent 80%);
    "
  />
  <div class="absolute inset-0 bg-background/50 backdrop-blur-[1px]" />
</div>
```

### 4. Image Elements (Next.js vs Astro)
Next.js uses `<Image fill className="object-cover" />` which appends position: absolute styles under the hood. In Astro, we replace `next/image` with `astro:assets` `<Image>` and explicitly write standard CSS layout classes:
```astro
import { Image } from 'astro:assets';
import profileImage from '../../public/profile.jpg'; // or public folder reference

<Image 
  src={profileImage} 
  alt="Aryan Sharma" 
  class="absolute inset-0 w-full h-full object-cover" 
/>
```

```astro
import Layout from '../layouts/Layout.astro';

import Hero from '../components/sections/Hero';
import Experience from '../components/sections/Experience';

    {/* Custom cursor (client-only as it binds to window on creation) */}
    <CustomCursor client:only="react" />
    
    {/* Page-wide scroll progress indicator */}
    <ScrollProgress client:load />
    
    {/* Pinned Hero Section */}
    <section class="sticky top-0 h-screen w-full overflow-hidden">
      <Hero client:load />
    </section>

    {/* Scroll-lifted content card container */}
    <div
      id="content-card"
      class="relative z-20 bg-[#202020] shadow-[0_-20px_50px_rgba(0,0,0,0.5)] border-t border-white/5"

    >
      <Experience client:visible />
      <ScrollingMarquee client:visible />
      <About client:visible />
      <Projects client:visible />
      <Contact client:visible />
    </div>
  </main>
</Layout>

<script>
  // Setup the lifted content card y-translate transition manually to match 1-1
  // with the framer motion scroll hooks used in next.js, maintaining maximum performance.
  const contentCard = document.getElementById('content-card');
  if (contentCard) {
    window.addEventListener('scroll', () => {
      const scrollY = window.scrollY;
      // Interpolate: starts at 10px y-offset at scrollY=0, catches up to 0px at scrollY=100
      const cardY = Math.max(0, 10 - (scrollY * 0.1));
      contentCard.style.transform = `translateY(${cardY}px)`;
    });
  }
</script>
```
